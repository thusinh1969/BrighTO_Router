# BrighTO-Router visual references

These assets are design references for DeepSeek and public documentation drafts. They are deterministic SVG files, so they can be edited in Git and rendered by GitHub. PNG previews are generated when the local renderer supports SVG conversion.

| File | Purpose |
|---|---|
| `github-banner.svg` | Public GitHub/README banner. |
| `portal-admin-mock.svg` | Admin Portal design reference: providers, routes, keys, usage. |
| `portal-user-mock.svg` | User Portal design reference: own API key, allowed models, usage, examples. |
| `benchmark-visual.svg` | Plain-language benchmark strategy visual. |

DeepSeek should use these as visual direction, not as mandatory pixel-perfect implementation. Keep the real Portal static/light unless a stronger product reason appears.
