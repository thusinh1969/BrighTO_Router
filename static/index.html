BrighTO-Router Portal

One control page for teams, models, budgets, and usage.

Set one admin key, connect provider backends, expose approved model routes, and create team API keys. The router keeps request routing fast; this Portal only manages control-plane settings.

Admin access

Use the value of ADMIN_MASTER_KEY from .env.

health: unknown ready: unknown providers: not loaded
Provider keys are set on the server with ./start.sh set-key provider api-key. The Portal never displays plaintext provider keys.

First-time setup path

1. Load providersVerify seeded OpenAI, Anthropic, Gemini, DeepSeek, Kimi, Qwen, Z.AI, OpenRouter, Meta Muse, and Custom.
2. Set provider keyRun ./start.sh set-key openai sk-... on the server.
3. Enable backendChoose the backend, confirm URL/format, then save.
4. Route and issue keyFetch models, create a route, then create a team API key.
